# Screenshot Layer Canvas

웹·앱 스크린샷을 올려서 화면 일부를 레이어로 떼어 내고, 옮기고 고치고 도형을 더해, 원본 크기 PNG로 저장하는 브라우저 앱입니다. 디자인 파일 복원기가 아니라 **시각적 목업 편집기**입니다. 서버·계정·외부 AI·유료 API 없이 전부 브라우저 안에서 동작합니다.

## 실행

```bash
npm install
npm run dev          # http://localhost:3000
```

| 명령 | 하는 일 |
|---|---|
| `npm run build` / `npm start` | 프로덕션 빌드와 실행 |
| `npx tsc --noEmit` | 타입 검사 |
| `npm test` | 단위 테스트(Vitest) |
| `npx playwright install chromium` | E2E용 브라우저 설치(처음 한 번) |
| `npx playwright test` | E2E(개발 서버를 자동으로 띄움, 브라우저는 한 번에 하나) |
| `NEXT_PUBLIC_E2E=1 npm run build` 후 `PW_PROD=1 npx playwright test` | 프로덕션 서버(`next start`)로 E2E |
| `PW_PERF=1 npx playwright test tests/e2e/perf.spec.ts` | 성능 측정(1920×1080) |
| `PW_PERF=1 npx playwright test tests/e2e/warp-perf.spec.ts tests/e2e/finger-perf.spec.ts` | 변형·손가락 도구를 4000×3000 화면의 큰 레이어에서 측정 |

Node 22 이상. 프로젝트 파일(`*.slc.json`)과 임시저장은 브라우저(IndexedDB)와 사용자가 받는 파일에만 있습니다.

## 쓰는 법

0. **시작**: 프로젝트가 없으면 세 가지 시작 방법이 보입니다 — 캡처 올리기, **빈 캔버스**(크기와 배경색을 고름, 모바일 390×844 · 데스크톱 1440×900 · 태블릿 820×1180 · 직접 입력, 한 변 최대 8192px; 영역 추출·자동 후보는 쓸 수 없음), **템플릿**(모바일 로그인·카드 목록·설정 화면). 편집 중에는 상단 바의 **새 프로젝트**로 같은 선택을 열 수 있습니다. 왼쪽 패널의 소스·템플릿은 그림 카드로 보이고, 사각형은 속성 패널에서 **모서리 반지름**을 정할 수 있습니다.
1. 캡처를 올립니다(파일 선택, 끌어다 놓기, Ctrl+V). 화면 프레임은 이미지의 원본 크기입니다. 프로젝트가 열려 있을 때 Ctrl+V나 캔버스로 끌어다 놓은 이미지는 새 레이어로 추가됩니다(교체하려면 "이미지 업로드" 버튼).
2. **영역 추출**(R)로 사각형을 드래그하면 그 부분이 레이어가 되고 원래 자리는 배경색으로 채워집니다.
3. 레이어를 끌어 옮기고, 모서리 점으로 크기를, 위쪽 둥근 점으로 회전을 바꿉니다.
4. 필요하면 **선**(L)·**사각형**(M)·**원**(O)을 그리고, **스포이트**(I)로 화면의 색을 읽어 씁니다. 이미지 레이어는 **변형**(W)으로 기울이기·원근·왜곡·뒤틀기를 하고(원본 픽셀은 그대로), **손가락**(F)으로 색을 번지게 할 수 있습니다.
5. **PNG 내보내기**로 저장합니다. 크기는 항상 업로드한 원본 크기이고, 투명한 부분은 투명 그대로입니다.

## 기능

**Phase 1 (MVP, 태그 `mvp`)**: 업로드, 원본 크기 프레임, 수동 사각형 추출, 레이어 선택·이동·복제·삭제·앞뒤 순서, 배경색 채움, Undo/Redo(100단계), zoom/pan, 원본 크기 PNG, 프로젝트 저장·불러오기.

**Phase 1.5**: 이미지 붙여넣기, 배경 채움 개선(그림자 감지), 단축키, 레이어 잠금·숨김·이름 변경, 크기 조절·회전(안티앨리어싱), 원본/수정본 비교, 레이어 복사·붙여넣기(시스템 클립보드), 임시저장(자동 복원, 여러 탭 안전).

**Phase 2** (진행 상황과 결정은 [`docs/ROADMAP_PHASE2.md`](docs/ROADMAP_PHASE2.md)): 선·도형·스포이트(벡터 레이어), 브러시·지우개, 텍스트 상자, 메모, 자동 영역 후보, 키보드 레이어 이동, 다중 선택·정렬 스냅 등. 후속: 붙여넣기·드롭으로 이미지 레이어 추가, 레이어 변형(비파괴, 스키마 v7), 손가락(번짐) 도구.

| 키 | 동작 |
|---|---|
| (기본 = 포토샵 프리셋; 설정에서 "이전 기본값"으로 바꿀 수 있음) V / H / M | 선택 / 이동 / 영역 추출 |
| U / I | 선→사각형→원(반복해서 누름) / 스포이트 |
| Ctrl+J · Ctrl+D · Ctrl+Shift+I | 레이어 복제 · 선택 해제 · 선택 반전 |
| Ctrl+] / [ · +Shift | 한 칸 앞/뒤 · 맨 앞/뒤 |
| Ctrl+0 · Ctrl+1 · Ctrl+= · Ctrl+- | 화면 맞춤 · 100% · 확대 · 축소 |
| Ctrl+S · Ctrl+O · Ctrl+X | 프로젝트 저장 · 열기 · 레이어 잘라내기 |
| Shift+T | 자유 변형(선택 전체를 감싸는 상자로 크기·회전; 상단·패널에 버튼도 있음) |
| Alt+끌기 · Space+끌기 | 복제하며 옮기기 · 잠시 손으로 이동 |
| (선택 도구) 빈 곳 끌기 | 상자로 여러 레이어 선택 (Alt: 완전히 포함된 것만) |
| 상단 "도움말" | 도구별 설명·예·막힐 때·현재 단축키, 첫 사용 안내 다시 보기 |
| B / E | 브러시 / 지우개 |
| Ctrl+G / Ctrl+Shift+G | 선택한 레이어를 그룹으로 묶기 / 그룹 해제(그룹은 프로젝트에 저장되고 하나처럼 이동, 패널에서 접기·이름 변경) |
| Ctrl+클릭 / Shift+클릭 | 선택 토글 / 레이어 패널에서 범위 선택(캔버스에서는 더하기). Ctrl+A 전체, Esc·빈 곳 클릭 해제 |
| (상단 바) 단축키 | 모든 단축키를 보고 바꾸기(충돌·브라우저 예약 키는 거부, 기본값으로 되돌리기, 이 브라우저에만 저장) |
| (왼쪽 패널) | 소스·템플릿: 내장 버튼·카드·입력창 등, 내 소스(선택한 레이어를 이름 붙여 저장, `.slc-assets.json` 내보내기·가져오기), 템플릿 3종(새 프로젝트로 열기 / 현재 화면에 추가) |
| Shift+W | 변형(선택한 이미지 레이어의 모서리·격자점을 끌어 왜곡·기울이기·원근·뒤틀기. 변 가운데 점 = 기울이기, Alt+모서리 = 원근, Enter 확정, Esc 취소) |
| R | 손가락(이미지 레이어 위에서 끌어 시작한 색을 번지게 함; 크기·강도·부드러움 조절) |
| A | 자동 후보(점선 후보를 클릭해 선택, 같은 자리를 다시 클릭하면 한 단계 큰 후보, Enter로 추출, Esc로 해제) |
| N | 메모(클릭하면 핀이 꽂히고 말풍선이 열림; 편집용이며 PNG에는 내보내기에서 "메모 포함"을 켰을 때만 들어감) |
| T | 텍스트(클릭하고 입력, Ctrl+Enter 확정, Esc 취소; 두 번 클릭하면 고침) |
| Ctrl+A | 모든 레이어 선택 (Shift/Ctrl+클릭은 선택에 더하기·빼기; 끌면 선택된 것이 함께 움직임) |
| Alt (끄는 동안) | 스냅 잠시 끄기 ("스냅" 스위치로 계속 끌 수도 있음) |
| 방향키, Shift+방향키 | 선택한 레이어를 1px / 10px 이동(원본 픽셀 기준, 연속 입력은 실행 취소 한 단계) |
| Ctrl+Z, Ctrl+Shift+Z (Ctrl+Y) | 실행 취소 / 다시 실행 |
| Delete | 레이어 삭제 |
| Ctrl+D | 레이어 복제 |
| Ctrl+C, Ctrl+V | 레이어 복사·붙여넣기(그림이 시스템 클립보드에 올라가며, 다른 곳에서 복사한 이미지는 프로젝트가 열려 있으면 새 이미지 레이어로 붙습니다) |

입력창에 포커스가 있거나 대화상자가 열려 있으면 단축키는 동작하지 않습니다.

## 구조

- `src/lib/` 순수 로직: 좌표 변환(`geometry/`), 이미지 처리·합성(`image/`), 프로젝트 스키마·검증·마이그레이션(`project/`), 저장소(`storage/`)
- `src/store/` Zustand 스토어와 immer 패치 기반 히스토리(이미지 픽셀은 복사하지 않습니다)
- `src/features/` 기능 단위 로직(가져오기, 내보내기, 저장·복원, 임시저장, 단축키, 클립보드)
- `src/components/editor/` UI(Konva 캔버스는 `"use client"` + `dynamic(ssr: false)`)
- `tests/unit`, `tests/e2e`, `tests/fixtures`(이전 빌드가 실제로 저장한 프로젝트 파일 포함)
- 규칙과 결정은 [`CLAUDE.md`](CLAUDE.md), 변경 내용은 [`docs/CHANGELOG_1_5.md`](docs/CHANGELOG_1_5.md)

## 알아둘 점

- 프로젝트는 **화면 1개**만 다룹니다(다중 화면은 범위 밖).
- 이미지 한 변은 8192px까지입니다.
- Chromium에서 검증했습니다. Firefox·Safari·터치 입력은 확인하지 못했습니다.
